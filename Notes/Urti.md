# Urti Easici

- Conservazione dell'energia cinetica
- Conservazione della quantitá di moto

## Energia Cinetica

K = 1/2mv\*\*2

## Quantitá di moto

P = mv

#### Sistema di riferimento per colpi elastici(no deformazioni interne)

    {
        Ktot(i) = Ktot(f)
        Ptot(i) = Ptot(f)
    }

##### Sistema completo di riferimento

    {
        1/2*m1(i)*v1(i)**2 + 1/2*m2(i)*v2(i)**2 = 1/2*m1(f)*v1(f)**2 + 1/2*m2(f)*v2(f)**2
        m1(i)*v1(i) + m2(i)*v2(i) = m1(f)*v1(f) + m2(f)*v2(f)
    }

### Sistema finale

    {
        v1(f)= (2*m2*v2(i)+m1*v1(i)-m2*v1)/(m1+m2)
        v2(f)= v1(i)+v1(f)-v2(i)
    }
